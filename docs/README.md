# Documentation de Village Survivor

La porte d'entrée de la documentation est **[`index.md`](index.md)**.

Ce fichier n'existe que parce que les forges Git affichent automatiquement le `README.md` d'un
dossier : il évite qu'un visiteur atterrisse sur une liste de fichiers bruts. Toute la
navigation, l'état de chaque document et les points ouverts vivent dans `index.md`, qui est le
document canonique de la méthode.
